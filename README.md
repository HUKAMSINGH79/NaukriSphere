## NaukriSphere Online Job Portal 

# Project Overview.....
NaukriSphere is a Java-based Online Job Portal web application developed using Java Servlets, JSP, JDBC, HTML, CSS, and MySQL.
The project allows job seekers to search and apply for jobs while recruiters can manage job postings and candidate applications.
This project follows the MVC (Model View Controller) architecture and is designed for learning enterprise Java web development concepts.
